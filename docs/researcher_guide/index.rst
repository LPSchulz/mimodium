Researcher Guide
================

Mimodium is intended for reproducible cell-free massive MIMO simulation
studies. When reporting results, record the Mimodium version together with the
workflow configuration and random seeds used to produce them.

.. admonition:: Citing Mimodium

   If Mimodium supports your research, please consider citing the software.
   Citation metadata and exportable citation formats are available from the
   repository's
   `CITATION.cff <https://github.com/LPSchulz/mimodium/blob/HEAD/CITATION.cff>`_.
